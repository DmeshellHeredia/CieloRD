# CieloRD Hito B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` task-by-task. Steps use checkbox syntax.

**Goal:** Entregar GPS, fotos, voz y mapa provincial totalmente offline,
integrados con las observaciones y con pruebas automatizadas.

**Architecture:** Adaptadores de plugins detrás de contratos C0, almacenamiento
privado con staging/reconciliación y un mapa GeoJSON pintado localmente. SQLite
sube a v3 solo para persistir el momento de captura GPS.

**Tech Stack:** Flutter 3.47.7, Dart 3.13.5, sqflite, geolocator 14.1.2,
image_picker 1.2.4, record 7.2.0, just_audio 0.10.6, path_provider 2.1.6,
image 4.13.1, crypto 3.0.8.

**Spec:** `docs/superpowers/specs/2026-11-22-hito-b-design.md`

## Global Constraints

- Sin red para funciones esenciales ni para el mapa.
- Sin ubicación en segundo plano ni posición antigua automática.
- Rutas relativas privadas; originales de galería nunca se eliminan.
- Máximo 5 fotos, 3 audios, 120 segundos por audio.
- `Result<T>`, modelos inmutables, `ChangeNotifier` e inyección por constructor.
- No Git, commits, push, merge, publicación ni Hito C.
- Cada cambio de producción nace de una prueba RED observada.

## Review Focus

- Proceso muerto entre copia de archivo y commit SQLite: reinicio elimina el
  huérfano sin perder medios vinculados (Task 4).
- Permiso GPS aproximado o denegado permanentemente: se mantiene la entrada
  manual y se muestra el fallo correcto (Task 2/7).
- Audio llega exactamente a 120 segundos mientras la UI está en background:
  se finaliza una sola vez y el archivo es válido (Task 5).
- GeoJSON corrupto o coordenada en el mar/fuera del bounding box: no hay crash
  ni marcador engañoso (Task 6/8).
- SQLite guarda medios pero falta el archivo: detalle ofrece fallback y no
  rompe Diario ni edición (Task 4/8).
